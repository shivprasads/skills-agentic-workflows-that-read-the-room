## Worth watching this week

- **Async merge API is generally available.** Merge single or stacked pull requests, or add them to a merge queue, by submitting a `PUT` and polling with `GET`. It is now the recommended way to merge programmatically. Source: [GitHub Changelog, Oct 1, 2026](https://github.blog/changelog/2026-10-01-github-async-merge-api-generally-available).
- **Dynamic workflows in Copilot CLI and the Copilot app.** Define multi-agent orchestration in code, mixing automated steps with agents that handle analysis. Source: [GitHub Changelog, Oct 1, 2026](https://github.blog/changelog/2026-10-01-dynamic-workflows-in-copilot-cli-and-the-copilot-app).
- **Copilot app for beginners: run several agents at once.** A friendly walkthrough of parallel agents. Source: [GitHub Blog](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-run-several-agents-at-once/).
